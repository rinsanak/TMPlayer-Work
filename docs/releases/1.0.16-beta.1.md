# TG Stream 1.0.16-beta.1

- Read the cold Home cache away from the UI thread, keeping newer library results.
- Include startup phases, CPU usage, main-thread scheduling delays, source opening and decoder timings in diagnostic recordings.
- Stop Log exports a ZIP to your own Telegram Saved Messages. Success is shown after Telegram confirms sending. If sending fails or remains unconfirmed, the ZIP is retained locally with copy/share recovery.
- Preserve the TG Stream package, application data, release signing certificate and existing playback behavior.

This test version is for collecting evidence on the affected Android TV. Playback lag improvements and Saved Messages delivery still require real-device verification. Diagnostic collection starts only when Start Log is selected; the bounded startup timing trail is included then. Telegram Saved Messages is cloud storage, not end-to-end encryption. No version of this APK has yet been built or tested locally at release preparation time.

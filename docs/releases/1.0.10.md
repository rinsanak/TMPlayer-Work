TG Stream 1.0.10

- Remove the Android Home Continue watching row and its controls. Keep saved positions and history.
- Reuse complete series discovery for previous/next episode buttons. Place compact transport at the top right, with times below the seek bar.
- Add persistent stereo Dialog Boost with speech presence, compression and peak limiting. Other sounds in a stereo mix may also change.
- Show known playback failure causes, preserve unknown error codes, and keep the current position during retry.
- Translate selected or loaded SRT/VTT/ASS/SSA subtitle files to Malayalam using a user-supplied Gemini API key. Consent is required before sending dialogue text to Google. The key is encrypted locally with Android Keystore. Original files and timestamps are preserved. Gemini quota or charges may apply; embedded subtitle tracks must first be available as files.
- Same-account Watch together sessions use Saved Messages for control state across networks. Both devices must open the exact same file copy and use the same Telegram account. No media or login credentials are shared. Create a session and join using its code. Device clocks should agree; sessions expire after two minutes without updates.

Package ID and release signing are unchanged. No Telegram files, login data or watch history are deleted.

# TG Stream 1.0.15

- Sync preferences, service API keys, watched marks and recent titles through the same Telegram account without a pairing code or password.
- Show the last seven distinct titles on Continue, including watched titles. Existing manual Watched and Unwatched actions remain available.
- Save short playback sessions, refresh positions on return and keep completed titles in recent history.
- Search every topic in a series source chat so a Recent card can discover all seasons.
- Keep library placeholders visible while Home loads, then fill them from cache and Telegram.
- Hand downloaded updates to the device system installer on TV, phone and tablet.

Sync uses the account's Saved Messages cloud storage, not end-to-end encryption. Local sync journals and the translation API key use Android Keystore encryption. Device permissions, PINs, downloaded files and storage paths remain local. Both devices must run this version for settings sync.
